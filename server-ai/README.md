# Server AI host services

The Compose profile `server-ai` starts the current lifecycle controller, read-only Docker observer, and SearXNG search service. It is usable without project applications or project database credentials. Source and query readers are legacy hosting adapters in the separate, opt-in `server-ai-project-readers` profile; enabling those adapters requires the operator-generated project token, source tree, TLS material, and read-only database credential files.

The controller runs without network access and reads its root-generated registry and private Unix socket. It needs the Docker socket to perform catalog-limited lifecycle operations. The observer reaches Docker only through the host's bounded, read-only socket proxy. Services drop capabilities, use read-only root filesystems, run as unprivileged users where applicable, and have resource limits. SearXNG settings, HMAC tokens, registry JSON, machine identity, and project/DB inputs stay in operator-managed files mounted read-only. No generated registry, project data, credential JSON, or key contents are included here.

The opt-in Control Center fragment is `compose.server-ai-control-center.yaml`; layer it onto the repository's existing Compose file so it augments the existing `control-center` service. It mounts the OpenAI API key file, operator-generated machine registry, host machine identity, server-admin HMAC token file, and protected admin socket directory. The app reads the key via `OPENAI_API_KEY_FILE` and the machine catalog via `SERVER_AI_MACHINE_REGISTRY_FILE`. The provider is the official OpenAI API with GPT-6 Luna. Keep key contents out of environment values, code, logs, and this repository.

This overlay does not include Ollama, local inference, or a VPN. Host paths, registry attestations, and network names need operator review for each machine. A future VPS with no applications and a new Cloudflare domain has not been deployed or validated, and this repository does not establish a completed full backup or restore.

For a new application-free VPS, follow [EMPTY-HOST.md](EMPTY-HOST.md). Version-2 controller enrollment binds only SearXNG and observer to reviewed root-owned paths and actual Docker identities; version-1 home registries remain supported. `compose.server-ai-empty-host-control-center.yaml` supplies the private socket/token and AI network attachments missing from the generic Control Center fragment. The enrollment script does not read any key/token contents or contact the OpenAI API.
